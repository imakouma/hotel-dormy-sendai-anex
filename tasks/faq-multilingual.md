# Spec Delta: 外国語14言語の定型回答

Status: implemented — ユーザーが2026-11-17に画面の外国語14言語すべてを指定。
既存仕様: [faq-capacity.md](faq-capacity.md)。既存の日本語FAQは維持。

## 目的と境界
全10ホテルで en/zh/zh-TW/ko/fr/de/es/it/th/vi/id/pt/tl/ms の定型質問に、実行時のAI・翻訳API・外部HTTPなしで同じ言語の回答を返す。対象はチェックイン時刻、チェックアウト時刻、朝食時間、Wi-Fi案内・パスワード・SSID・無料かの7意図。外国語の料金、忘れ物、夜鳴きそば、内線、予約固有の依頼などは従来AIへ。日本語の既存6系統（7項目）は変更しない。

日本語の館内資料だけを事実の根拠とし、UIに残る別ホテル由来の翻訳は流用しない。ホテル別の時刻・最終入店・プラン例外・会員条件・無料の明記有無を確認する。14言語の共通文言とホテル別事実を組み合わせる。資料全体のSHA-256と一致しない場合は外国語FAQを無効にし、古い時刻等を返さない。資料更新時は事実データを再確認してハッシュを更新する。ハッシュだけの自動更新は禁止。

## 実装範囲・計画
1. 実APIルートのHTTPを差し替え、外国語FAQが外部呼出し0件となるテストを先に追加。
2. `lib/hotel-faq-localized.ts` に全文一致の質問リストと整形処理、`data/faq-locales.json` に14言語の文言、`data/hotel-faq.json` にホテル別の確認済み事実を追加。`lib/hotel-faq.ts` の外国語分岐から利用。
3. 14言語、10ホテルの事実、資料変更、複合質問、未対応質問、APIキーなし、日本語回帰を検証。既存AI経路テストは外国語の別の非FAQ質問へ変更。
4. 全10ホテルに適用し、テスト・型検査・lint・ビルド、code-only Graphify更新、本番反映後のAPI確認。

## 成功条件・検証
- 14言語すべてで朝食時間、Wi-Fi案内が外部呼出し0件。
- 情報のある9ホテルでチェックイン・アウト、明記のあるホテルのみパスワード・SSID・無料を回答。
- 最終入店とラストオーダーを区別。会員・プラン条件を落とさない。
- 時刻や資料変更時、未対応・複合・個別質問時はnull、既存AI経路へ。
- 既存 `{ reply }` と `X-Hotel-Answer-Source` を維持。新依存・新事業者・資格情報・ログ追加なし。
- `node --test tests/*.test.cjs`、`npx tsc --noEmit`、`npx eslint lib/hotel-faq*.ts tests/hotel-faq*.cjs`、`npm run build`。

翻訳は実装時に用意する。実際の利用時にはAIを使わない。母語話者による校閲と実トラフィックでの対応率測定は別途。

## 対応パターン数
日本語: 6系統、チェックインとアウトを分けて7項目。正規表現で言い換えを受け付けるため、固定文の件数としては管理していない。
外国語: 7意図、14言語で302の登録表現。英語30、簡体字24、繁体字24、韓国語21、フランス語22、ポルトガル語21、その他8言語各20。大小文字、全角、疑問符などの差も吸収する。各ホテルで根拠のないパスワード等は一致してもAIへ回すので、302件すべてを全ホテルが直接回答できるという意味ではない。

## 更新とロールバック
`data/hotel-info.md` の変更後は、`data/hotel-faq.json` の時刻・条件・接続情報を原文と照合し、必要な翻訳文言を更新したうえで `sourceSha256` を原文UTF-8全体のSHA-256へ更新する。ハッシュだけを追従する自動処理は設けない。未更新の間は外国語質問が従来AIへ戻り、日本語FAQは従来どおり現在の資料を参照する。
ロールバックは本変更コミットをrevertし再デプロイする。プロバイダーやデータベースの変更なし。

## レビュー
料金を尋ねられて営業時間だけを返さないよう、外国語の朝食は時刻質問だけに限定。Wi-Fi料金・パスワード・SSIDはそれぞれ根拠のある値/無料の明記が必須。日本語の館内資料にないベルエアの入退室時刻や、ドーミー系のWi-Fiパスワードを作らない。元資料の料金・会員条件・最終入店を目視照合済み。APIの形式、入力検証、非FAQのAI経路は維持。
実際のTypeScript設定に合わせ、APIテストのトランスパイルにも `esModuleInterop: true` を指定し、JSONのdefault importを本番と同じ条件で検証する。
