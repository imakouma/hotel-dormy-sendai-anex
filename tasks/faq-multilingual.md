# Spec Delta: 外国語14言語の定型回答

Status: implemented — ユーザーが2026-11-17に画面の外国語14言語すべてを指定。
既存仕様: [faq-capacity.md](faq-capacity.md)。既存の日本語FAQは維持。

## 目的と境界
全10ホテルで en/zh/zh-TW/ko/fr/de/es/it/th/vi/id/pt/tl/ms の定型質問に、実行時のAI・翻訳API・外部HTTPなしで同じ言語の回答を返す。対象はチェックイン時刻、チェックアウト時刻、朝食時間、Wi-Fi案内・パスワード・SSID・無料か、夜鳴きそば、フロント内線、忘れ物方針に、朝食料金・駐車場・大浴場を加えた13意図。追加3意図は日本語にも対応。予約固有の依頼、個別の忘れ物の照会や発送依頼などは従来AIへ。既存日本語の6系統（7項目）は維持する。

日本語の館内資料だけを事実の根拠とし、UIに残る別ホテル由来の翻訳は流用しない。ホテル別の時刻・最終入店・プラン例外・会員条件・無料の明記有無を確認する。14言語の共通文言とホテル別事実を組み合わせる。資料全体のSHA-256と一致しない場合は外国語FAQを無効にし、古い時刻等を返さない。資料更新時は事実データを再確認してハッシュを更新する。ハッシュだけの自動更新は禁止。

## 実装範囲・計画
1. 実APIルートのHTTPを差し替え、外国語FAQが外部呼出し0件となるテストを先に追加。
2. `lib/hotel-faq-localized.ts` に全文一致の質問リストと整形処理、`data/faq-locales.json` に14言語の文言、`data/hotel-faq.json` にホテル別の確認済み事実を追加。`lib/hotel-faq.ts` の外国語分岐から利用。
3. 14言語、10ホテルの事実、資料変更、複合質問、未対応質問、APIキーなし、日本語回帰を検証。既存AI経路テストは外国語の別の非FAQ質問へ変更。
4. 全10ホテルに適用し、テスト・型検査・lint・ビルド、code-only Graphify更新、本番反映後のAPI確認。

## 成功条件・検証
- 14言語すべてで朝食時間、Wi-Fi案内が外部呼出し0件。
- 情報のある9ホテルでチェックイン・アウト、明記のあるホテルのみパスワード・SSID・無料を回答。
- 最終入店とラストオーダーを区別。会員・プラン条件を落とさない。
- 時刻や資料変更時、未対応・複合・個別質問時はnull、既存AI経路へ。
- 既存 `{ reply }` と `X-Hotel-Answer-Source` を維持。新依存・新事業者・資格情報・ログ追加なし。
- `node --test tests/*.test.cjs`、`npx tsc --noEmit`、`npx eslint lib/hotel-faq*.ts tests/hotel-faq*.cjs`、`npm run build`。

翻訳は実装時に用意する。実際の利用時にはAIを使わない。母語話者による校閲と実トラフィックでの対応率測定は別途。

## 対応パターン数
日本語: 既存の6系統（7項目）に加え、朝食料金・駐車場・大浴場の3意図を36表現で登録。朝食料金は既存の朝食系統にも含まれるため、質問項目は合計9項目。既存の正規表現による言い換えは固定文の件数として管理していない。
外国語: 13意図、14言語で761の登録表現。英語66、簡体字55、繁体字55、韓国語52、フランス語55、ポルトガル語54、その他8言語各53。大小文字、全角、疑問符などの差も吸収する。各ホテルで根拠のないパスワード等は一致してもAIへ回すので、761件すべてを全ホテルが直接回答できるという意味ではない。

## 更新とロールバック
`data/hotel-info.md` の変更後は、`data/hotel-faq.json` の時刻・条件・接続情報を原文と照合し、必要な翻訳文言を更新したうえで `sourceSha256` を原文UTF-8全体のSHA-256へ更新する。ハッシュだけを追従する自動処理は設けない。未更新の間は外国語と新しい日本語の駐車場・大浴場FAQが従来AIへ戻る。既存の日本語FAQ（朝食料金を含む）は従来どおり現在の資料を参照する。
ロールバックは本変更コミットをrevertし再デプロイする。プロバイダーやデータベースの変更なし。

## レビュー
料金を尋ねられて営業時間だけを返さないよう、朝食の料金と時刻を別意図として照合する。Wi-Fi料金・パスワード・SSIDはそれぞれ根拠のある値/無料の明記が必須。日本語の館内資料にないベルエアの入退室時刻や、ドーミー系のWi-Fiパスワードを作らない。元資料の料金・会員条件・最終入店を目視照合済み。APIの形式、入力検証、非FAQのAI経路は維持。
実際のTypeScript設定に合わせ、APIテストのトランスパイルにも `esModuleInterop: true` を指定し、JSONのdefault importを本番と同じ条件で検証する。

## 追加対応 — 夜鳴きそば・フロント内線・忘れ物（2026-11-17）
ユーザーの追加指定により既存方式を3意図・184表現拡張。実行時のAI・外部HTTPなし、資料ハッシュ不一致は従来AIに戻す。既存日本語FAQとAPI形式は維持。

- 夜鳴きそば: EXPRESS／青森／ANNEXの3ホテル。21:30–23:00、無料。EXPRESSの変更可能性、青森のアレルゲン等は公式案内参照という注意を保持。
- 内線: EXPRESS・青森は7、シルクは333、ジャストイン・Ace・Granteras・Crown・Bellea・ANNEXは9。資料にない那覇は推測しない。
- 忘れ物: EXPRESS・ジャストイン・青森・Bellea・ANNEXは原則連絡なし、連絡がなければ3か月後処分、飲食物は即日。Granteras・Crownは保管依頼なく残置され、チェックアウト後7日以内（食品1日以内）に申し出がなければ放棄とみなし処分、その場合連絡なし。Ace・シルクは保管依頼なく残置された物を所有者が放棄したものとしてホテル規定で処分（日数は創作しない）。那覇は資料なし。
- 忘れ物回答末尾には、資料に記載されたフロント内線を案内する。物品が見つかった、預かっている、発送を受け付けたとは答えない。個別品の照会やアレルギー判断はAIへ。

実装手順: 失敗する実APIテストを追加 → 既存の3分類・翻訳データ・ホテル別事実を拡張 → 14言語の実ルートと全登録表現、欠落情報、旧資料、複合・個別依頼を検証 → 全10ホテルで回帰検証と本番確認。

追加対応の検証: 公開する内容だけをHEADから一時ディレクトリへ取り出し、今回のFAQ差分を重ねた状態で全10ホテル・合計1,218テスト成功。14言語の追加3項目は、根拠のあるホテルでAIキーなし・外部HTTP0件。登録486表現を全件確認。型検査・lint成功、Aceのwebpackビルド成功、code-only Graphify更新済み。回答先を誤ってWi-Fiに変更するmutationで忘れ物の条件テストが失敗することも確認。並行作業中のプロバイダー変更は本コミットに含めない。

## 追加対応 — 朝食料金・駐車場・大浴場（2026-11-17）
日本語＋画面で選べる外国語14言語、全10ホテル。追加3意図は日本語36・外国語275、合計311表現。全文一致の既存照合・ホテル別事実・文言の仕組みを拡張し、AIも翻訳APIも呼ばない。依存追加なし。

- 朝食料金: 金額記載の8ホテルでは税込表記、子供の年齢区分、無料対象、目安・宿泊者限定、朝食券購入条件を保持。Ace・那覇は金額を推測せず、未掲載としてフロントへ案内する。
- 駐車場: 情報のある6ホテルは駐車場ごとの料金、時間、車高・寸法、途中出庫・予約条件を保持。青森は資料に従って最新の台数・料金を公式アクセスページへ案内。残り4ホテルは未掲載としてフロントへ案内。固有名詞と住所は検索に使えるよう日本語原表記を保持。
- 大浴場: EXPRESSの男性専用と女性向け他館案内、青森・ANNEXの翌朝終了とサウナだけの休止、Crownの曜日別・男女別入替時間を保持。Granterasは「なし」と明記。他5ホテルは未掲載としてフロントへ案内し、「なし」や「無料」を推測しない。
- 追加3項目は資料不足でも上記の確認先を定型回答し、AIを使用しない。ただし未登録の言い回し、複合質問、個別見積り、現在の空車状況、予約・安全判断は従来のAI経路へ。
- Ace資料の曖昧な「時間帯によっては駐車場車庫があります」は閉鎖時間を創作せず、利用予定時間についてフロント確認と表現する。
